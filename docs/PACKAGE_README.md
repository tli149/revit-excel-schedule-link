# Excel Schedule Link 0.9.4 (Pilot) — for Autodesk Revit 2024

This package shows an Excel worksheet inside Revit as a schedule view and lets
you reload it with one click when the workbook changes.

**Before you install**

- Revit **2024** only.
- Pilot release: try it on a copy of a project first and keep backups.
- The DLLs and scripts are **not digitally signed**; Windows may warn you.
- Unblock this ZIP (right-click → Properties → Unblock) **before** extracting.

**Install:** close Revit, then right-click `scripts\install-revit2024.ps1` →
**Run with PowerShell**.
