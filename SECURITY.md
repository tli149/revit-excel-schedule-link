# Security policy

## Supported versions

| Version | Support |
|---|---|
| 0.9.x | Supported on a best-effort basis; the latest 0.9.x pilot release is the supported version. |

Older releases are not maintained.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub: open the
repository **Security** tab and choose **Report a vulnerability**. Do not open
a public issue for an unpatched security problem.

Never attach client or project files, including RVT or XLSX files. Do not
include internal filesystem paths, user names, or other identifying project
information. Describe the smallest reproducible behavior with sanitized
examples instead.

The maintainer will make a best-effort acknowledgement, investigation, and
fix. Response times are not guaranteed.

For ordinary bugs and feature requests, use GitHub Issues.
